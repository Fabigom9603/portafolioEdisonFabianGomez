✅ Sistema de Gestión de Tareas (Mini SaaS)

Descripción:
El Sistema de Gestión de Tareas es una aplicación web completa tipo mini SaaS desarrollada bajo una arquitectura Frontend + Backend desacoplada, orientada a la organización personal de tareas mediante autenticación segura, CRUD completo, filtros y búsqueda en tiempo real.

El sistema combina un backend REST API desarrollado en Node.js + Express, un servicio de autenticación con JWT y encriptación de contraseñas con bcrypt, una base de datos PostgreSQL con relaciones, y un frontend moderno construido con React + TypeScript + Tailwind CSS. El proyecto está desplegado en producción: frontend en Vercel y backend + base de datos en Railway.

⚙️ Arquitectura del sistema

La aplicación está dividida en tres capas principales, cada una con responsabilidades claramente definidas y desplegada de forma independiente.

🔹 Frontend – React + TypeScript + Tailwind CSS
  • Interfaz moderna y responsiva construida con React 18 y TypeScript.
  • Estilos con Tailwind CSS para diseño rápido y consistente.
  • Estado global de autenticación mediante Context API.
  • Comunicación con backend usando Axios e interceptores para manejo automático de tokens JWT.
  • Componentes reutilizables: TaskList, TaskForm, Layout, Login, Register.
  • Desplegado en Vercel con despliegue automático desde GitHub.
🔹 Backend – API REST (Node.js + Express)
  • API REST desarrollada en Node.js + Express.
  • CRUD completo de tareas con endpoints protegidos.
  • Autenticación JWT con middleware personalizado.
  • Encriptación de contraseñas con bcrypt.
  • Arquitectura profesional: controllers / models / routes / middleware / utils.
  • Variables de entorno para configuración segura.
  • Desplegado en Railway.
🔹 Base de Datos – PostgreSQL
  • Base de datos relacional PostgreSQL.
  • Tablas: users y tasks.
  • Relaciones con clave foránea (user_id en tasks).
  • Eliminación en cascada (ON DELETE CASCADE).
  • Fechas automáticas con CURRENT_TIMESTAMP.
  • Alojada en Railway con respaldo automático.

📦 Funcionalidades implementadas

🔹 Autenticación de usuarios
  • Registro de nuevos usuarios con validaciones.
  • Inicio de sesión con generación de token JWT.
  • Almacenamiento seguro del token en localStorage.
  • Cierre de sesión con limpieza de datos.
  • Protección de rutas según autenticación.
🔹 CRUD de tareas
  • Crear nuevas tareas con título y descripción.
  • Leer listado completo de tareas del usuario.
  • Actualizar título, descripción o estado (completada/pendiente).
  • Eliminar tareas con confirmación previa.
  • Marcar como completada con checkbox.
🔹 Filtros y búsqueda
  • Filtro por estado: Todas / Pendientes / Completadas.
  • Contadores visuales para cada categoría.
  • Búsqueda en tiempo real por título o descripción.
  • Combinación de filtros + búsqueda.
🔹 Diseño responsivo
  • Interfaz adaptada a móviles, tablets y desktop.
  • Header con nombre de usuario y botón de cierre de sesión.
  • Footer con información del proyecto.
  • Modal para crear/editar tareas.
  • Efectos hover y feedback visual en todas las acciones.

🔐 Seguridad y buenas prácticas

  • Autenticación basada en JSON Web Tokens (JWT).
  • Tokens almacenados en localStorage y enviados en cada petición.
  • Middleware de validación y expiración de tokens en backend.
  • Hash seguro de contraseñas con bcrypt (SALT automático).
  • Variables de entorno para JWT_SECRET y credenciales de BD.
  • Interceptor de Axios para agregar token automáticamente.
  • Validaciones del lado del cliente y del servidor.
  • Código documentado profesionalmente en español.

🌐 Despliegue en producción

  • Frontend: Desplegado en Vercel con CDN global y HTTPS.
  • Backend: Desplegado en Railway con PostgreSQL integrado.
  • Base de datos: PostgreSQL en Railway con respaldo automático.
  • CI/CD: Despliegue automático desde GitHub en ambas plataformas.
  • Variables de entorno: Configuradas para desarrollo y producción.
