📱 SurtiNoxSmart — Gestión inteligente para pequeños comercios

SurtiNoxSmart es una aplicación Android desarrollada con Kotlin y Jetpack Compose, diseñada para facilitar la gestión de pequeños comercios desde un solo lugar.

Permite administrar ventas, inventario, gastos, ganancias, reportes y alertas, utilizando una base de datos local para trabajar sin depender de una conexión a internet.

📱 Descargar APK

🛠️ Tecnologías y arquitectura

  • Kotlin
  • Jetpack Compose + Material 3
  • Room / SQLite para persistencia local
  • ViewModel + Repository Pattern
  • Coroutines y Flow
  • WorkManager para tareas en segundo plano
  • Gson para manejo de datos
  • Separación de responsabilidades entre interfaz, lógica y acceso a datos

📦 Módulos principales

📦 Inventario

Gestión de productos, categorías, precios, costos y existencias, incluyendo búsqueda, ajuste de stock y control de stock mínimo.

🛒 Ventas

Creación de cuentas, selección de productos, control de cantidades, cálculo del total y registro de las ventas realizadas.

💰 Ganancias y gastos

Registro de gastos y cálculo de ganancias a partir de las ventas, costos de productos y gastos operativos.

📊 Reportes

Estadísticas sobre ventas, productos más vendidos, ventas por categoría y hora, gastos y utilidad del negocio.

🔔 Alertas

Notificaciones para productos con stock bajo o agotado y recordatorios relacionados con gastos.

⚙️ Configuración

Administración de los datos del negocio, preferencias, notificaciones y respaldo de información.

⚡ Características destacadas

  • Base de datos local con Room / SQLite.
  • Búsqueda de productos sin importar mayúsculas o tildes.
  • Paginación para optimizar la carga del inventario.
  • Estado reactivo mediante StateFlow y Coroutines.
  • Notificaciones programadas mediante WorkManager.
  • Exportación y respaldo de la información.

💾 Respaldo y notificaciones

La aplicación incorpora un sistema de alertas en segundo plano y permite exportar la información del negocio para facilitar su respaldo y conservación.

🚀 Resultado

SurtiNoxSmart integra en una sola aplicación la gestión de ventas, inventario y finanzas, combinando una interfaz moderna con almacenamiento local, reportes, alertas y herramientas de respaldo.

El proyecto me permitió desarrollar y aplicar conocimientos en desarrollo Android, Kotlin, Jetpack Compose, arquitectura, bases de datos, lógica de negocio y diseño de interfaces.
